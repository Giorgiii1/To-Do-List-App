# To-Do List App ✅

A simple To-Do List application** built with **HTML, CSS, and JavaScript.  
It allows users to **add, check/uncheck, and delete tasks**, and saves them locally using **localStorage** so tasks persist even after closing or refreshing the browser.

## Features
- Add new tasks 📝
- Mark tasks as completed ✅
- Delete tasks ❌
- Tasks are saved locally using localStorage
- Responsive and easy-to-use interface

## Technologies
- HTML
- CSS
- JavaScript
- LocalStorage
